BUILD NOTES
At rest: one chip. No chip rows, no groups. FILTER ⌄ leads the row (ink border, 44px, mono 11/600); the count sits right-aligned opposite it. IMPORT and + NEW keep their header places on every state.
Filtered: one token per active filter, each removing itself. Token = 44px tall, 12px leading pad, label mono 11/600 cream, then a 44×44 ✕ cell. Fill is the type color for a type token and ink for every other kind, matching the selected-state rule. Tokens wrap to a second line and keep 6px gaps. CLEAR ALL is a 44px control on the count line, accent label, shown only while something is on.
Sheet: the five groups, then a counting primary. Slides up over the list, surface fill, 1px ink border, dismissible by backdrop tap or the primary. Groups are TYPE, TIME, PAIN (4-cell grids), then LAST DONE and SOURCE sharing a line as 2-cell grids. The level-1 button reads the live result: “Show 12 workouts”, and disables at “No workouts match”.
Filter semantics. TYPE single-select and toggles off. TIME and PAIN multi-select as unions. LAST DONE mutually exclusive (<21D / 21D+). SOURCE mutually exclusive (GLOBAL / CUSTOM). Tokens are per group, not per band: contiguous bands inside one group collapse into a single range token (pain 4 and 5 selected renders one PAIN 4–5 token), and a non-contiguous selection renders one token listing them (PAIN 1, 4). The header count counts tokens, so the row and the count always agree.
RETIRED The accent ALL chip, the eleven-chip ragged wrap, the single PAIN ≤3 chip, and the words RECENT / NOT RECENT. Count copy is “35 WORKOUTS” at rest and “12 OF 35 SHOWN” when filtered: “entered” described the data-entry backlog, not anything the rower cares about.
