# Phase 5E — Builder Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-lay the builder so a six-step workout is scannable on one phone screen, per the design review's handoff.

**Architecture:** An accordion replaces the permanently-expanded rows: at most one step is open (`editing`), the rest collapse to ~86px summary cards with inline actions. The metadata pickers move into one classification card; rest and SPM become steppers; the existing state module gains presentation helpers but its conversion logic is unchanged.

**Tech Stack:** React 19, react-router-dom 7.18.2, Vitest 4 + Testing Library, Playwright 1.62.

## Global Constraints

- **The design authority for this screen is `docs/design/builder-redesign/README.md`** (committed this phase), superseding `docs/design/README.md` §11. It is high-fidelity: recreate at 390px width. `Builder redesign.dc.html` is the prototype — read it for behaviour, do NOT port its code or `support.js`.
- Spec: `docs/superpowers/specs/2026-07-30-phase-5e-builder-redesign-design.md`. Departures from the handoff recorded there and binding: **SPM wakes at 20** (handoff says 18) · **pace offset clamps ±60** (handoff says −15…+30) · **`wu` and standalone rest steps still render** (handoff models only work steps) · **collapsed delete confirms first** (handoff deletes immediately) · **`Save to library` is kept**.
- **`app/domain/**` is untouched.** Verify with an empty diff before the PR. It stays at 100% coverage. All bounds remain its: `w` time 0.5..180 half-step · `w` distance int 100..42195 · `spm` **optional** int 10..60 · `restMinutes` **optional** 0.5..60 half-step · `wu`/`r` minutes 0.5..180 half-step · `reps.count` 1..12 · at most one marker never last · ≥1 work/test step · title 1..80 · pain 1..5 · ≤100 emitted steps.
- **Rest stores minutes.** The handoff's stepper works in seconds for display (`m:ss`); 30-second increments map exactly onto the domain's 0.5-minute half-steps. Never store seconds.
- **These must not regress** (each cost a review round to get right): the repeat span stays derived from `BOOKEND_ROW_KINDS`; `hasMidSpanReps` still refuses to open a workout whose stored marker the row model can't place; SPM stays genuinely optional (empty ⇒ no `spm` field); client bounds mirror `validate.ts` with the server as authority; the Phase 5 exit criterion resolves `1:59.0–2:01.0`.
- Every tappable ≥44×44px; WCAG AA (text ≥4.5:1, meaningful graphics ≥3:1); **2px radii everywhere; no shadows; no animation; no gradients**. Colours from `app/src/theme/tokens.css` — never raw hex in a rule.
- Screens must NOT import `@capacitor/*`, `./platform`, or `./native/*` (lint-enforced); platform behavior goes through `src/adapters/`.
- Tests assert real behavior, not mock behavior (docs/TESTING.md); no snapshots; no assertion-free tests. TDD: failing test first, RED evidence in the report. Expected pace strings are HARDCODED, never recomputed via the production functions.
- **Check per-file coverage for files you touch**, not just the 90×4 aggregate — uncovered branches have hidden behind the aggregate repeatedly in this project.
- **Run `pnpm e2e`**, not just unit+client. Three times in recent phases a builder change left the e2e suite red because only unit tests were run.
- pnpm only, ESM only. Work in the `phase-5e` worktree; **before every commit run `git rev-parse --show-toplevel` and confirm it prints the worktree path.** No merge without James's explicit approval.

### Task 1: Accordion state, rest bridge, and summary formatting

**Files:**
- Modify: `app/src/builder/builderState.ts`, `app/src/builder/builderState.test.ts`

**Interfaces:**
- Produces: `BuilderRow` gains nothing; `rest` remains the existing minutes string. **Do not change the stored shape.**
- Produces: `export const REST_STEP_SECONDS = 30`, `export const REST_MAX_SECONDS = 900`
- Produces: `export function restSecondsFromRow(row: BuilderRow): number` — `""` → `0`; otherwise `minutes × 60` rounded to the nearest whole second.
- Produces: `export function rowWithRestSeconds(row: BuilderRow, seconds: number): BuilderRow` — clamps to `0..REST_MAX_SECONDS`, snaps to a multiple of `REST_STEP_SECONDS`, writes back **minutes** (`""` at zero, else `String(seconds / 60)`).
- Produces: `export function fmtRestSeconds(seconds: number): string` — `m:ss`, or `"NONE"` at zero.
- Produces: `export function stepSummary(row: BuilderRow): string` — `20′ @ 6k +10` or `2000 m @ 2k ±0`. Offset renders `+n` / `−n` (U+2212) / `±0`.
- Produces: `export function stepSubSummary(row: BuilderRow): string` — `20 spm · rest 1:30`; omit the spm term entirely when spm is empty; rest reads `rest none` at zero.
- Produces: `export const PAIN_WORDS: readonly string[]` — `["EASY BREATH","COMFORTABLE","WORKING","HURTS","BRUTAL"]`, indexed `pain - 1`.
- Produces: `export function addStepLike(f: BuilderForm): { form: BuilderForm; id: string }` — appends a copy of the LAST row's values, or a default row (`5` MIN / `6k` ±0 / spm `22` / rest `1` minute) when the list is empty. Returns the new row's id so the caller can open it.
- `cloneRow` keeps its signature but must now also return the new id: change to `export function cloneRow(f: BuilderForm, id: string): { form: BuilderForm; id: string }` and update its existing callers/tests.

```ts
describe("rest seconds bridge", () => {
  it("reads an empty rest as zero seconds", () => {
    expect(restSecondsFromRow({ ...workRow("a"), rest: "" })).toBe(0);
  });

  it("reads minutes as seconds", () => {
    expect(restSecondsFromRow({ ...workRow("a"), rest: "1.5" })).toBe(90);
  });

  it("writes seconds back as minutes, snapped to the 30s step", () => {
    const row = rowWithRestSeconds(workRow("a"), 90);
    expect(row.rest).toBe("1.5");
    expect(rowWithRestSeconds(workRow("a"), 100).rest).toBe("1.5");
  });

  it("clears rest at zero rather than storing 0", () => {
    expect(rowWithRestSeconds({ ...workRow("a"), rest: "2" }, 0).rest).toBe("");
  });

  it("clamps at the 15-minute ceiling", () => {
    expect(rowWithRestSeconds(workRow("a"), 99999).rest).toBe("15");
  });

  it("every reachable rest value is a legal domain half-step", () => {
    for (let s = 0; s <= REST_MAX_SECONDS; s += REST_STEP_SECONDS) {
      const rest = rowWithRestSeconds(workRow("a"), s).rest;
      if (rest === "") continue;
      const minutes = Number(rest);
      expect(minutes * 2).toBe(Math.round(minutes * 2)); // 0.5 steps
      expect(minutes).toBeLessThanOrEqual(60);
    }
  });

  it("formats seconds for display", () => {
    expect(fmtRestSeconds(0)).toBe("NONE");
    expect(fmtRestSeconds(90)).toBe("1:30");
    expect(fmtRestSeconds(600)).toBe("10:00");
  });
});

describe("summaries", () => {
  it("summarises a minutes step with a signed offset", () => {
    expect(stepSummary({ ...workRow("a"), durValue: "20", durUnit: "min", refBase: "6k", refOff: 10 }))
      .toBe("20′ @ 6k +10");
  });

  it("summarises a metres step and renders a zero offset as ±0", () => {
    expect(stepSummary({ ...workRow("a"), durValue: "2000", durUnit: "m", refBase: "2k", refOff: 0 }))
      .toBe("2000 m @ 2k ±0");
  });

  it("renders a negative offset with a real minus sign", () => {
    expect(stepSummary({ ...workRow("a"), durValue: "5", durUnit: "min", refBase: "6k", refOff: -2 }))
      .toBe("5′ @ 6k −2");
  });

  it("omits the spm term when spm is free", () => {
    expect(stepSubSummary({ ...workRow("a"), spm: "", rest: "1.5" })).toBe("rest 1:30");
  });

  it("says rest none at zero", () => {
    expect(stepSubSummary({ ...workRow("a"), spm: "20", rest: "" })).toBe("20 spm · rest none");
  });
});

describe("addStepLike", () => {
  it("copies the last row's values and returns the new id", () => {
    const base = formWith({ rows: [{ ...workRow("a"), durValue: "90", durUnit: "m", refOff: -4, spm: "26" }] });
    const { form, id } = addStepLike(base);
    expect(form.rows).toHaveLength(2);
    expect(id).toBe(form.rows[1].id);
    expect(form.rows[1]).toMatchObject({ durValue: "90", durUnit: "m", refOff: -4, spm: "26" });
  });

  it("uses a sensible default when there are no rows", () => {
    const { form } = addStepLike(formWith({ rows: [] }));
    expect(form.rows[0]).toMatchObject({ kind: "w", durValue: "5", durUnit: "min", refBase: "6k", refOff: 0, spm: "22" });
  });
});
```
