Amendment 2026-09-05 to the Concept2 connect handoff. Spec: docs/superpowers/specs/2026-09-05-concept2-auto-send-design.md (rev 3, two antagonist passes folded). Every frame is at real proportions on the app's own tokens; every colour pairing below is a computed ratio, not a judgement. The gate is the approval, not the presentation — each GATE 0 DECIDES is a question James answers on sight.

What a rower reads differently. On /you/concept2 the linked card's Unlink Concept2 button becomes a three-position control — OFF · MANUAL · AUTOMATIC — with one line beneath it saying what the mode does. OFF is the two-tap unlink (arm kept). The card's status pill and the You row both gain one new word, SEND FAILED, when Concept2 has refused every send for want of a weight class. Nothing else on any screen moves.

Rulings already made (James, 2026-09-05): OFF is unlinked · AUTOMATIC is silent at save time · a fresh link lands in MANUAL · no backlog send · client-side after save · failures surface on the You row · only no_weight_class raises the flag.

1a The mode line's copy GATE 0 DECIDES

Two candidates per mode are drawn in the frames above and here in words. The spec's recommendation is the first of each.

MANUAL: (a) Send each finished monitor row yourself, from the log. — (b) Rows are sent when you tap Send on them.

AUTOMATIC: (a) Finished monitor rows are sent when you save them. — (b) Every finished monitor row goes to Concept2 as you save it.

Both are --ink-3 on --surface, 12px — the identity line's own treatment (7.43:1).

2 · OFF, armed — the two-tap unlink lives in the control

Ruling 1 makes OFF destructive, so it keeps the arm the Unlink button had: the first tap arms, and while armed the OFF segment spans the whole control — it becomes today's full-width Tap again to unlink button exactly (52px, --accent fill, the button's own sentence case), centred, with MANUAL and AUTOMATIC out of reach until the arm clears. The disclosure sentence appears, the 4-second caption counts down, the second tap unlinks; disarming restores the three segments with the current mode pressed. RF23: this is the only unlink affordance on the screen — the button it replaces is gone. 9 · Built (2026-09-05) — what departs from the frames

APPROVED 2026-09-05 with one fix on sight (2a). Every recommendation in §8 shipped as drawn, with one placement departure recorded here rather than silently:

  • Landscape mode line. §1's landscape frame draws the mode line in the TELL column under the identity and the control alone in the ACT column; the portrait frames draw identity → hairline → control → mode line. One DOM cannot honour both, so the built card keeps the portrait order and in landscape the mode line sits in the act column beneath the control (the same class of departure 1f already records for its identity line). Portrait is the primary surface and reads exactly as drawn.
  • The remedy link-out is .c2-card-linkout: --ink mono 12px at 44px, as §4a's frame and §7's row draw it — not the log block's accent link-out, since §7 rules --accent gains no new use.
  • Segment padding 0 4px so AUTOMATIC's caps never touch the hairline at 375px; widths measured ≥ 104px in portrait.
