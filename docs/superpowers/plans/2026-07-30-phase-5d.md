# Phase 5D — Builder Simplification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the builder's per-row repeat marking, fix the name generator, and turn the remaining free-text fields into finger-friendly controls.

**Architecture:** The repeat block stops being chosen per row and becomes derived: leading *bookend* rows (today `wu`, later `cd`) sit outside the repeat span, everything else repeats `×N`. The `SET` cell becomes a clone button, duration and SPM become stepper/toggle controls, and warm-up leaves the workout entirely for a preference read at session time.

**Tech Stack:** React 19, react-router-dom 7.18.2, Vitest 4 + Testing Library, Playwright 1.62.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-30-phase-5d-builder-simplification-design.md`. `docs/design/` is the UI authority EXCEPT where `docs/design/DEVIATIONS.md` overrides.
- **The domain does not change this phase.** `app/domain/**` stays at 100% coverage and untouched. All bounds remain its: `w` time 0.5..180 half-step · `w` distance int 100..42195 · `w.spm` **optional**, int 10..60 · `w.restMinutes` **optional**, 0.5..60 half-step · `wu`/`r` minutes 0.5..180 half-step · `reps.count` 1..12 · at most one marker, never last · ≥1 work/test step · title 1..80 · pain 1..5 · max 100 steps.
- **Rest stays minutes-only** — no unit toggle, ever. Rest has no pace ref, so meters could not be converted to time for totals or the timer. Rejected deliberately; see the spec.
- **SPM stays optional.** Empty is valid and must round-trip as absent. No value may be written into a rower's existing data by merely opening a workout.
- Every tappable ≥44×44px; WCAG AA (text ≥4.5:1, meaningful graphics ≥3:1); 2px radii; no shadows; no animation. Colors from `app/src/theme/tokens.css` — never raw hex.
- Screens must NOT import `@capacitor/*`, `./platform`, or `./native/*` (lint-enforced); platform behavior goes through `src/adapters/`.
- Tests assert real behavior, not mock behavior (docs/TESTING.md); no snapshots; no assertion-free tests. TDD: failing test first, RED evidence in the report.
- Expected pace strings in tests are HARDCODED, never recomputed via the production functions.
- **Check per-file coverage for files you touch**, not just the 90×4 aggregate — four tasks across the last two phases shipped uncovered branches that the aggregate hid.
- pnpm only, ESM only. Work in the `phase-5d` worktree; **before every commit run `git rev-parse --show-toplevel` and confirm it prints the worktree path.** No merge without James's explicit approval.
