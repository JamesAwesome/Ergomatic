# Connected + timer mode — revision for the build

**Date:** 2026-08-11 · **From:** design · **For:** implementation
**Mockup:** `Ergomatic connected mode.dc.html`, sections 3 (Live), 4 (Grid), 5 (Timer mode)
**Scope:** deltas only. Everything not listed here is unchanged from the 2026-08-05 packet.

Frames in the mockup are exact: landscape 844×390, portrait 390×844, no scroll.

---

## 1 · Connected mode is two panes

Delete the timer pane from connected mode. Panes are **LIVE** and **GRID**; lands on LIVE,
remembers the last pane per rower. Horizontal swipe anywhere toggles them, 60px threshold.

The phone timer is untouched for unconnected sessions — see §4.

---

## 2 · The pane rail lives in the sensor gutter (landscape)

Landscape already reserves 44pt beside the camera housing. Put the rail **inside** it:

```
gutter  width 44  bg #efeade  border-right 1px #d8d3c4
        flex column · justify-content: space-between · padding 12px 0
        [LIVE 44×44]  [housing spacer 11×104 r6]  [GRID 44×44]
```

Content column starts immediately after the gutter — no extra inset, no right-edge rail.
Dot 10×10, label mono 9px; active ink `#1b1a17`, inactive `#c9c3b2` square + `#57544c` label.

Portrait keeps a 54px two-tab bar (LIVE · GRID) above the home indicator.

**End session** is no longer a full-width button. It is a 44pt outlined control in the header:
mono 11px/600, `#b5341f` text and 1px border, radius 2, padding 6/10. Staging unchanged
(first tap → `TAP AGAIN` for 4 s). In landscape timer mode it sits in the gutter instead.

## 3 · Live pane

Two heroes, each with its target directly beneath. Targets are **ink**; only the actual takes
the off-target colour (ochre `#8a5f18` over, teal `#2a6275` under, ink on). Captions never
re-word.

| element | landscape | portrait |
|---|---|---|
| actual split, actual rate | 112px / 500 weight / lh 0.92 | 104px / lh 0.90 |
| split tenths | 58px | 54px |
| `TARGET` label | mono 11px, ls 0.14em, `#57544c` | same |
| target value | **46px** | **44px** |
| left-in-interval · meters · HR | 30px, one baseline row under a 1px ink rule | 30px, three columns |
| UP NEXT | one line, label 11px + value 20px, right-aligned | band, label 11px + value 16px |
| TOTAL LEFT | label 11px + **22px** value, inline with the ¼ ruler bar | same |

Layout notes for the build:

- Hero column is `flex` column with **`min-width:0`**; the numeral span is `white-space:nowrap`.
  Split renders `m:ss` at full size + `.t` at half. Anything slower than `9:59.9` → `—`.
- The old three metric cards are gone; the metric row costs 44px, not 120.
- Missing HR renders `—` in place. No dashed card, no explanatory copy.
- Landscape UP NEXT string: `REST 2:00 · then WORK 2:09.0`. Portrait shortens to
  `REST 2:00 · WORK 2:09.0` — at 390px the long form cannot fit on one line.
- Interval segment bar 4px, 12 segments; total-left bar 5px with quarter ticks. Unchanged.

## 4 · Grid pane

Single-line rows, fixed height, no second line and no indent.

| | landscape | portrait |
|---|---|---|
| row height | 36px | 40px |
| value type | mono 19px | mono 19px |
| row number | mono 13px | mono 13px |
| rows visible | 8 | 12 |
| columns | # · TIME · METERS · /500M · SPM · HR · REST | # · TIME · METERS · /500M · SPM · HR |

- Column flex: `#` fixed 26 (22 portrait), TIME 1, METERS 1, /500M 1.1, SPM 0.6, HR 0.6, REST 0.8.
- **Completed** rows: values ink over a 1px `#ded8c9` rule.
- **Active** row: background `#fffdf7`, 1px ink rule top *and* bottom, 4×20 ink marker left of
  the number. No card padding, no 2px box. Countdown accent `#b5341f`; split and rate carry the
  off-target colours.
- **Upcoming** rows: programmed values `#57544c` over a 1px dashed `#c9c3b2` rule.
- Session totals moved into the header line: `3 OF 12 · WORK · 0:47 LEFT` and `38:20 TOTAL`.
  No second header block, no footer button.
- Rows scroll under the pinned header; always scroll the active row into view; state the number
  of rows below in words.

## 5 · Timer mode (not connected)

Same fixes applied; no machine to read, so there is no actual and nothing is coloured but the
countdown.

- **Landscape gutter** holds back (`←`, top) and END (bottom) either side of the housing. Portrait
  puts both on the header line.
- **Countdown** 128px landscape / 118px portrait, ink; `ELAPSED` beneath at 26px.
- **Targets** stacked in the right column: `TARGET · /500M` and `TARGET · SPM`, both 56px
  landscape / 52px portrait, both ink. Split carries its baseline caption (`6K PACE`).
- **Pause** is the only level-1 control: 200×44 landscape beside UP NEXT, full-width 56px portrait.
- UP NEXT and TOTAL LEFT follow the live-pane spec above.
- Status word stays `RUNNING` here; `ROWING` belongs to connected mode.
- Distance pieces swap the hero: meters count down at 128px, the clock accrues at 26px beneath.
  Labels swap, layout does not move.
