# Phase 5C — Builder Refinements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the seven usability defects James hit authoring a workout on his phone, and retire the `num` column that no longer has a job.

**Architecture:** Three layers move. The database gains `sort_order` and stops requiring `num`; the domain's duration grammar accepts bare minutes and its bulk header accepts an optional leading number; the builder replaces free-text pace refs with a structured control, drops the `No.` field, focuses the first invalid field on save, and hands bulk import its own screen.

**Tech Stack:** Postgres 18.4 + Drizzle 0.45.2, Express 5, React 19, react-router-dom 7.18.2, Vitest 4 + Testing Library, Playwright 1.62.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-30-phase-5c-builder-refinements-design.md`. `docs/design/` is the UI authority EXCEPT where `docs/design/DEVIATIONS.md` overrides.
- **Binding deviations already in force:** pain is 1–5; difficulty reads EASY/MEDIUM/HARD; the repeat block is positional (`setRowIds`, never a per-row filter); the SPM field is 44px. This phase ADDS: no workout numbers anywhere in the UI.
- **Hard requirements:** every tappable ≥44×44px; all text WCAG AA (≥4.5:1); meaningful graphics ≥3:1; 2px radii; no shadows; no animation.
- **Colors from tokens** (`var(--*)` in `app/src/theme/tokens.css`) — never raw hex in components.
- **Domain bounds are the single source of truth** (`app/domain/validate.ts`): title 1..80 · pain 1..5 · steps non-empty, max 100 · `wu`/`r` minutes 0.5..180 in 0.5 steps · `w` time duration 0.5..180 half-step · `w` distance 100..42195 int · `w.spm` 10..60 · `w.restMinutes` 0.5..60 half-step · pace ref `abs(off) <= 60` · `reps.count` 1..12 · at most one reps marker, never last · ≥1 work/test step. The client mirrors these; the server stays the authority.
- **Typing and pasting must agree.** Any change to duration parsing lands in BOTH `app/src/builder/builderState.ts`'s `parseDurationInput` and `app/domain/bulk.ts`'s `parseDuration`. 5B established and fuzz-verified this property; it must not regress.
- **Migrations are expand-only this phase.** Add `sort_order`; make `num` nullable; drop `num`'s unique indexes. **Do NOT `DROP COLUMN num`** — that is Phase 6's first commit, because `scripts/deploy.sh` rolls back to the previous image on an unhealthy deploy and old code still selects the column.
- Domain imports from client code use `.js` specifiers (`../../domain/pace.js`); do NOT add a Vite alias.
- Screens must NOT import `@capacitor/*`, `./platform`, or `./native/*` (lint-enforced); platform behavior goes through `src/adapters/`.
- Tests assert real behavior, not mock behavior (docs/TESTING.md); no snapshots; no assertion-free tests. TDD: failing test first, RED evidence in the report.
- pnpm only, ESM only, server imports use `.js` extensions. Coverage gate 90×4; `domain/**` stays **100** — it changes this phase, so its tests grow with it.
- Work in the `phase-5c` worktree; **before every commit run `git rev-parse --show-toplevel` and confirm it prints the worktree path.** No merge without James's explicit approval.
