Why A (revised)

James, 2026-08-31: a shaded box instead of the em-dash. A shaded box with a border (James, revised again): fill --rule-2, border --rule-3, no glyph. Sized EXACTLY like its neighbours by construction, not by eye — it is the same .type-badge box with two no-break spaces as content (two mono characters wide, same font, same padding, the 1px border compensated in padding). Since #233's type validation, no supported writer can create such a row, so the equality is pinned by class-sharing in a client test rather than measured live.

Why not B

Dropping the badge ragged-lefts the name against its neighbours and makes the absence look like a rendering bug rather than a statement. B is honest but reads as broken.

Swap logic unchanged

Either way, an unreadable type still never manufactures a swap mark — this decision is only about what the badge slot shows.

2 · The self-contradicting mark

A row can be LINKED to one workout while its saved title claims another (a malformed request, or a client bug). Identity decides the mark, display keeps the snapshot — so today such a row reads 2K Test with INSTEAD OF 2K Test beneath it. True, but it reads as a contradiction. It also has an honest sibling that is common: a personal workout genuinely titled 2K Test produces the same wording.

Now contradiction
  • 7AN2K Test✓INSTEAD OF 2K Test
C · recommended the mark names the miss, not the title
  • 7AN2K Test✓NOT THE PRESCRIBED 2K Test
D keep INSTEAD OF everywhere
  • 7AN2K Test✓INSTEAD OF 2K Test

Why C, and its scope

Only when the displayed name EQUALS the prescription it missed: the mark switches to NOT THE PRESCRIBED 2K Test, which is true of both producers (the personal same-title workout, and the cross-linked row). Every other swap keeps INSTEAD OF <x> unchanged.

Why not D

D costs nothing but leaves a rower who authored their own 2K Test reading a sentence that contradicts itself on the plan's three most important days.

Width

NOT THE PRESCRIBED 2K Test is 25 characters of 11px mono on its own variant-B line: ~165px of 330 available. No clipping in either orientation.
